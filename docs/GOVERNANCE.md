# P2E 解耦、治理与回滚记录

本轮接续既有 P2E 成果，正式工程为肥鱼助手 / Fat-Fish-Assistant。新 Git 候选从自有源码开始，旧仓库及历史完整保留在本地内部 Backup；没有导入原 Git 父提交、上游 ZIP、wheel、完整插件副本或私人数据。

## 依赖与源码边界

统一清单入口为 manifests/index.json。sources.json 固定五个外部源码提交、官方下载地址、归档哈希、许可证来源与兼容补丁哈希；chat/speech/build 固定软件包版本及文件哈希。Python wheel 从固定版本的官方 PyPI 元数据解析**指定文件名与同一哈希**，没有匹配即失败，不回退到其他版本或镜像文件。资产清单分别管理解释器、NapCat、引擎和权重，不把代码许可推导为权重许可。

管理页面另由 dashboard.json 固定官方 v4.29.3 发布包和 SHA，安装时预置到密封 release。启动器只接受该固定兼容目录，拒绝缺失或版本不兼容，避免 AstrBot 首次启动隐式下载或进入上游的 TLS 降级重试分支。前端载荷同样不进入仓库；上游及其前端依赖声明仍适用。

运行代码分为自有 src、动态组装的上游源码/插件、不可变发布清单与实例数据。selfreply 仅动态取得判断子集及 LICENSE，不安装第二个自主消息发送器。自有 guard 只注册 canonical 模块，旧名称是薄导入别名。必要安全补丁继续保留，不能用通用插件钩子覆盖不了的方案替换。

|修改位置|保留原因|
|---|---|
|核心 feiyu_p2c、preprocess、waking、whitelist|统一早期准入、实例身份与群权限，拒绝越权绕行|
|核心 context_utils、scheduler、process/internal|作用域、引用和任务上下文贯穿处理链|
|核心 agent hooks、tool_loop、respond|撤权传播、工具与最终发送边界校验|
|核心 builtin astrbot/main|原生命令与既有权限适配|
|LivingMemory memory_scope/passive_group_capture/vector_retriever|记忆分域、被动捕获及检索边界|
|continuous_message 四文件|合并上下文、引用线程与原生插件兼容|
|meme_manager|固定原版，无补丁|

每份补丁均有上游提交、文件前后 SHA、原行段、补丁 SHA、应用脚本和失败拒绝机制。实际官方字节组装与升级回退在隔离夹具执行。撤销采用重建并切回已校验的旧发布；不在活动上游目录反向编辑。插件管理随版本整体校验、升级和回滚，不宣称支持任意热卸载。

## 已退出的旧路径

旧安装入口 Install-Feiyu、provision、fetch_wheels、lock_wheels 及 examples 中四份重复依赖锁已归档；它们对内置载荷和旧目录的假设由统一安装器替代。旧阶段实验、plugin_review、旧自有 p2c/p2d/p2e、旧候选完整 Git 和载荷不再属于正式构建或公开包。

旧部署仍引用的启动/维护宿主原位保留且未改写，完整副本另在 Backup，避免整理影响既有路径。安装中的 vendor、解释器、环境、NapCat、模型、实例和数据库不移动。OpenClaw 继续静态封存。本地原路径、原因、逐文件哈希及恢复方法详见维护者的 Backup/INDEX.json；该内部索引不公开。

## 安装与运行治理

解释器、缓存、版本目录和实例位于仓库外。环境在最终路径创建，成功完成安装、pip check 和逐项版本核验后登记；Windows 启动器不随环境移动。失败构建有本项目标记才允许归档重试；未知目录、损坏缓存、版本漂移拒绝复用。可选资产在唯一 stage 解包，收据记录内容哈希；不登记半成品。

重复安装保留实例。活动或脏实例拒绝安装和配置变化；跨操作 OS 锁拒绝并发写配置。外部只读登记不等于接管，生命周期操作拒绝执行。默认只回环监听，不增加主人、群白名单或远程管理入口。

## 回滚与边界

源码基线、旧 Git bundle/检出及逐批修改副本均在本地 Backup。工程归档只移动或保留兼容副本，未不可逆删除。代码升级失败、进程中断、损坏发布和显式回滚已由合成空白实例测试；数据库恢复与索引修复工具沿用既有实现，本轮不新增迁移演练。

当前机器原依赖关键文件哈希不变。跨日检查发现旧 Chat/模型进程已不存在且旧运行标记残留；未据此自动清标记或启动现有实例。候选启动验证只使用空白隔离实例，不能替代真实 QQ 或 VM 证据。待 VM 验收与维护者确认后，再决定正式切换；本轮结束即停止，不进入后续阶段。
