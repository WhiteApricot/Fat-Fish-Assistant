## R-02 近期授权与确认

- 身份 — 主人私聊、测试好友、授权群
- 步骤 — 申请给测试账号授予全局管理员，先说「撤销刚刚的管理员申请」，再说「确定」。重做申请，用「确定」确认授予。随后询问刚刚做了什么，再说「撤销刚刚的管理员申请」。在确认撤销前查询名单，并在另一个会话尝试确认（在群里先 @ 肥鱼助手），最后在原私聊说「确定」并再次查询。
- 预期 — 未确认的申请可取消，取消后「确定」不变更权限。已完成授权可在近期引用。撤销已生效的全局授权会建立一项新待确认操作，只有发起者在原会话确认后才移除。其他会话看不到这项私聊操作的上下文。

## R-03 Dashboard 隐藏输入与重启复用

- 身份 — 同一 Windows 账户下的本机启动者
- 步骤 — 在测试 Dashboard 更改密码，关闭并重新启动肥鱼助手。第一次输入时可粘贴密码，观察输入是否隐藏。确认终端提示已保存。再完整停止并启动一次。
- 预期 — 第一次用与 API Key 相同的隐藏输入，验证后由 Windows 加密保存。下一次启动复用密码并打开已登录页面。已启用二次验证时，浏览器仍要求完成二次验证，终端无需重复保存密码。
