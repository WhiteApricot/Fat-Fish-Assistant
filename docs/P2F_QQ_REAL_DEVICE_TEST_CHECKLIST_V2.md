# P2F QQ 实机复测清单 v2

日期为 2026-11-03。上一版实测及原始证据保留在原清单。已有实例先停止服务，再通过安装向导的修复流程更新已安装发布包，然后双击一键启动。先通过 R-01 和 R-07 核对菜单，以免误测旧发布包。

合并转发直接使用锁定 NapCat Node v4.18.41 的 get_forward_msg。它接受 id 或 message_id 并返回 messages。锁定 AstrBot 适配器会保留原始 OneBot 事件，即使组件转换未保留转发段，项目插件仍可从该事件恢复转发 ID。GitHub 候选插件也使用同一接口，接口未返回的节点、媒体和时间字段需要在复测时记录。相关依据见 [NapCat API](https://napneko.github.io/develop/api)、[continuous_message](https://github.com/aliveriver/astrbot_plugin_continuous_message) 和 [cross_session_awareness](https://github.com/TaiLaaa/astrbot_plugin_cross_session_awareness)。

QQ 电话与自定义通话音频封存。现有公开 OneBot 接口未发现适用的 QQ 通话动作，GitHub 上的 numalarm 使用 Windows 桌面自动化。[NapCat API](https://napneko.github.io/develop/api) · [numalarm](https://github.com/magicapple123/numalarm)
