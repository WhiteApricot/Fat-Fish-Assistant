# 账号与权限

## 首次设置

新实例创建空身份目录。先配置一个支持私聊验证的通信连接。在该连接的私聊发送 `/owner`，然后在同一私聊发送 Bot 返回的 `/owner 验证码`。验证码五分钟内有效，绑定到 Provider 平台、实例和账号。首个成功确认的账号获得唯一主人身份。

普通账号通过验证后登记为访客。在机器人私聊发送 `/invite`，五分钟内在另一个平台的机器人私聊发送 `/link 邀请码`。绑定后两个账号使用同一个身份和角色。目标账号如已有独立身份，绑定会清除原身份及其私有长期记忆和偏好。已有多个有效绑定的目标需先解除其他绑定。使用 `/unlink 平台 实例 账号` 申请解绑并在当前私聊确认。最后一个主人绑定受保护。

## 操作权限

| 操作 | 权限 |
| --- | --- |
| 私聊初始化主人 | 已接入平台的验证私聊，且尚未初始化主人 |
| 邀请绑定 | 有效访客及以上角色，另一平台账号用邀请码验证 |
| 私聊聊天 | 当前账号有效，且至少为普通成员 |
| 群聊聊天 | 群已准入，当前账号未被全局或本群封禁，满足群模式 |
| 准入或关闭群 | 主人在同平台私聊确认，也可在目标群内 @机器人发起并确认 |
| 全局管理员任免 | 主人私聊确认 |
| 普通角色变更 | 主人或符合目标角色限制的全局管理员在私聊确认 |
| 群成员管理、模式与共享开关 | 当前已准入的管理员，变更受当前群范围约束 |
| 私聊记忆 | 当前账号绑定的本人身份 |
| 群聊记忆 | 当前已授权群范围，修改受卡片归属和群管理权限约束 |
| 主动投递 | 创建者仍具备会话权限，代设群提醒时接收者也须获准 |
| 解绑 | 账号所属身份或主人，最后一个主人绑定受保护 |

平台原生群成员资料可用于理解聊天背景。FFA 独立校验会话访问、管理角色和记忆可见范围。
