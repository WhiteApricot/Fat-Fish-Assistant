# 账号与权限

## 首次设置

新实例创建空身份目录。先配置一个支持私聊验证的通信连接。在该连接的私聊发送 `/ffa-owner`，然后在同一私聊发送 Bot 返回的 `/ffa-owner 验证码`。验证码五分钟内有效，绑定到 Provider 平台、实例和账号。首个成功确认的账号获得唯一 Owner UUID。

普通账号通过验证后登记为访客。访客可以发起账号绑定，聊天权限由角色和会话授权决定。发送 `/ffa-invite 平台 实例 账号`，由目标账号在指定连接的私聊发送 `/ffa-link 验证码`。已绑定账号可以继续邀请其他账号，角色来自共同的 Principal。使用 `/ffa-unlink 平台 实例 账号` 申请解绑并在当前私聊确认。最后一个 Owner 绑定受保护。

## 操作权限

| 操作 | 权限 |
| --- | --- |
| 私聊初始化 Owner | 已配置 Provider 的验证私聊，且实例尚无 Owner |
| 邀请绑定 | 有效访客及以上角色，目标账号独立确认 |
| 私聊聊天 | 当前账号有效，Principal 至少为普通成员 |
| 群聊聊天 | 群已准入，当前账号获本群授权，满足群模式 |
| 准入或关闭群 | Owner 在同平台私聊确认 |
| 全局管理员任免 | Owner 私聊确认 |
| 普通角色变更 | Owner 或符合目标角色限制的全局管理员私聊确认 |
| 群成员管理、模式与共享开关 | 当前已准入的管理员，变更受当前群范围约束 |
| 私聊记忆 | 当前账号绑定的本人 Principal |
| 群聊记忆 | 当前已授权群范围，修改受卡片归属和群管理权限约束 |
| 主动投递 | 创建者当前仍有目标会话权限；代设群提醒时接收者也须获准 |
| 解绑 | 账号所属 Principal 或 Owner，最后一个 Owner 绑定受保护 |

平台原生群成员资料可用于理解聊天背景。FFA 会话授权保存在身份目录，管理角色和记忆 Scope 分别校验。
