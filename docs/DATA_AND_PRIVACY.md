# 数据与隐私

安装根与源码分开。聊天 SQLite、插件数据及索引位于 instance/data，权限、身份及密钥位于 instance/private，人格资源位于 instance/persona。管理和服务日志分别写入安装根 logs 和 instance/logs。Dashboard 凭据使用 Windows DPAPI，与 Windows 用户和机器相关。

云端模型可收到本轮消息、获准读取的引用与附近消息、近期脱敏指令回执、人格指示及检索材料。自然语言提醒会调用模型提取时间与事项，严格参数提醒可直接执行。联网工具只提交当前问题整理出的公开查询或用户给出的公开链接，`/websearch off` 可关闭当前会话的搜索和链接阅读。直接发送的语音交由 DeepSeek 转写，准入的文件上传到 DeepSeek，供本轮主 Agent 读取。文件引用在本轮结束时请求删除，上传时同时设置一小时过期。链接的签名状态只在进程内短期保留，按会话和发言者隔离。请勿在聊天、日志或截图中提供密钥及个人敏感数据。

启用统一记忆后默认对授权私聊开启长期记忆。群聊默认关闭，须由有权限的管理员告知成员并在该群执行 `/memory on`。停用后暂停对应范围的摄取和召回。日常上下文只读取活跃卡片，完整档案通过显式命令查询。参见 [长期记忆](MEMORY.md)。

换机使用 [加密迁移包](MIGRATION.md)。平台连接与统一记忆的配置示例位于 [examples/config](../examples/config)。实例中的私密配置、数据库和运行日志应保存在安装目录。

卡片投影在每次请求时检查来源授权。群共享撤销后，已建立的私聊投影不再参与召回。完整互动证据可在当前授权范围用 /memory history 查询。

启用后台语义分析时，当前来源会话的模型可收到经筛选的正文和同一私聊范围的少量相关事实候选。绑定账号共享低敏互动画像，私人原文留在原记忆作用域。获准的公开 Bot 经历来自受信回执。已有撤回与重置机制也使相关分析任务和派生数据失效。

可信宿主核验的公开素材可进入独立公开经历投影。该投影只存公开内容及不可直接识别私聊的证据摘要值。撤销私人关联和删除公开经历是两个操作，公开删除也受恢复擦除账本保护。
