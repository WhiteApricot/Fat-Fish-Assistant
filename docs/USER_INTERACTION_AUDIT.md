### NapCat 修复及测试边界

原问题是先严格查询全局所有同名进程，再按路径过滤。无关 Node 进程不可读取或 Get-Process 无法取得路径时，会在过滤前中断整个操作。现在使用 Windows 有限查询权限读取可执行路径和创建时间；发现扫描中的不可读取候选不参与控制，已经登记的受管 PID 则单独严格查询，失败仍拒绝操作。Node 模式要求官方布局特征，不因父目录恰有 node.exe/index.js 就误判。包哈希、PID、创建时间、精确路径和启动锁继续保留，没有随意终止无关进程。

Windows PowerShell 简化测试已通过：语法、Node/Shell 识别、无关候选过滤、不可查询的受管 PID 拒绝操作、合成启动/拒绝重复启动/父子进程停止、单键输入、Ctrl+C、双行进度和下载校验回退。没有操作正式运行实例，也没有重跑完整安装、真实 QQ 登录或 Sandboxie。**Sandboxie 本轮尚未验证**；文件夹对话框、许可长文阅读和真实扫码仍由用户人工验收。

镜像候选、官方回退、版本锁和文件哈希没有改动。核心仍为 141 包，语音仍使用原独立依赖组；本轮仅改为安装界面默认选择语音，不额外裁剪依赖或更换模型。之前报告的“不含语音默认组合投影”不再代表新的界面默认选项。

**出错时怎么办**：按原因检查日志或运行安装修复。关闭启动窗口不会自动停止后台服务。结束后 Windows 会提示按键关闭窗口，具体文字随系统语言变化。

## 4. 环境检测与异常修复

**用户看到什么**：重新运行安装，显示“检测到已有环境：1 重复检查（默认）；2 修复/继续中断安装（会正常停止服务）。现有聊天、身份及权限不会替换。”，询问“请选择 1 或 2”。

**用户应该做什么**：只检查时回车或输入 1；修复中断安装时输入 2。修复会停止服务。

**程序接下来做什么**：检查环境和网络，或按原配置修复。软件已安装但设置未完成时，会显示“软件已安装，将继续完成上次未完成的设置。已有聊天和设置会保留。”，直接续接设置。

**成功后看到什么**：“检查完成，已有安装可以使用。”。检查或修复后仍会进入启动。

**出错时怎么办**：“电脑或网络检查未通过，请查看诊断日志后重试。”表示检查未过。未知目录、文件被修改、服务仍在写入时，程序可能拒绝继续，以保留原数据。Sandboxie 的 WMI、网络或控制台限制，应另在普通 Windows 下复验。

## 5. 数据迁出

**用户看到什么**：双击迁移文件，显示“迁移向导：1 迁出当前肥鱼助手；2 从迁移包导入（目标不能已有实例）。”，询问“请选择 1 或 2”。

**用户应该做什么**：输入 1。按“迁出会正常停止全部服务，并暂停源实例以避免两个主机同时消费同一 QQ。继续请输入 YES”确认，选择保存位置。按“设置迁移密码（至少 12 个字符；请妥善保管）”设置密码，再按“请再次输入迁移密码”确认。

**程序接下来做什么**：停止服务、检查数据、打包并加密；暂停原电脑上的助手，避免两台电脑同时使用该 QQ。

**成功后看到什么**：“迁移包已保存：{位置}”“包含 {数量} 个数据文件，大小 {大小} MB”“文件校验码 SHA256：{校验码}”，以及“迁出完成。只需搬运这个加密包；源实例已暂停，请保持停止，在目标主机选择导入。”。本次结束，不再自动启动。

**出错时怎么办**：“两次密码不一致”时重新输入。“已取消迁出”“已取消保存”表示操作取消。失败后先确认原电脑状态，不要同时启动两台。只有确认目标电脑停止且不再使用此 QQ，才能在原电脑重新运行安装，按“源实例因迁出已暂停。只有目标主机已停止且不再使用此 QQ 时，输入 YES 撤销暂停”恢复。

## 6. 数据迁入

**用户看到什么**：迁移菜单选择 2，出现迁移包选择窗口，随后询问“请输入迁移密码”，要求“选择新的空安装目录，不得覆盖现有实例”。

**用户应该做什么**：选择迁移包，输入密码，选择空文件夹。按“确认源主机已经停止并保持暂停，目标是唯一使用此 QQ 的实例：请输入 YES”确认，并阅读接受许可。

**程序接下来做什么**：显示“准备固定版本运行环境；随后验证密码、数据和依赖版本，自动恢复到新实例。”，准备组件、校验并恢复，再进入登录。迁移包不包含全部软件安装包。

**成功后看到什么**：“已恢复 {数量} 个数据文件。正在准备登录…”。按首次登录步骤扫码，直到出现连接成功和就绪提示。

**出错时怎么办**：密码错误、版本不匹配或目标已有实例时停止导入；使用新空目录重试，不要覆盖旧安装。“已取消导入”表示取消；“尚未确认源实例停止”表示未确认原电脑停机。原电脑继续保持暂停，直到明确只使用哪一台。
