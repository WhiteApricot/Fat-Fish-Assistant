# P2F 权限及指令风险分类

## 身份与迁移

主人 > 全局管理员 > 群管理员 > 普通好友 > 非好友。先检查全局和本群黑名单，再检查身份、群开放状态与操作作用域；主人也不能绕过黑名单。好友关系仍由 OneBot 成功返回的好友列表确认。

原有 owner、group_admins、approved_groups、groups、blocked、group_blocked 均保留。新增 global_admins，缺省为空，不自动把原群管理员提升为全局身份。废弃的非空 admins 字段仍拒绝静默加载，避免来源不明的旧身份被提升；原有明确迁移工具不变。

为兼容既有原生入口，主人保持等级3，群管理员保持2，新增全局管理员为2.5；好友1，陌生人0，拒绝-1。新身份严格位于主人和群管理员之间，原生“小于3”的安全隔离继续有效。身份修改由程序检查，模型不参与授权。

## 权限表

|能力|主人|全局管理员|群管理员|好友/普通群成员|
|---|---|---|---|---|
|管理全局管理员名单|允许，变更需确认|只允许查看|拒绝|拒绝|
|白名单和常规全局Bot设置|允许|允许|拒绝|拒绝|
|设置群管理员|允许，授予需确认|允许，授予需确认|拒绝|拒绝|
|已授权群的模式、冷却、人格、共享记忆|允许|所有授权群允许|仅本人管理的群|拒绝管理|
|全局黑名单|允许|允许，但不能拉黑主人或其他全局管理员|拒绝|拒绝|
|群黑名单|允许|允许|仅本群，不能拉黑受保护管理者|拒绝|
|私人记忆、表达与提醒|仅本人会话|仅本人会话|仅本人会话|好友本人会话|
|群提醒|管理本群任务|管理授权群任务|管理本群任务|管理自己的本群任务|
|为其他人建提醒|仅授权群内明确@一人|同左|仅本群明确@一人|拒绝|
|原生未列入菜单的核心/插件管理入口|保留原主人边界|继续隔离，防止安装代码或绕过网关|拒绝|拒绝|

全局管理员不能修改主人身份，不能通过群管理员命令改写任何全局身份。在已开放的群，NapCat 上报的当前发言者如果是 QQ 群主或群管理员，自动取得同群 Bot 群管理员权限。继承仅用于当前群和当前请求，不写入显式名单，不延伸到私聊、其他群或全局。QQ群撤权后，下条普通成员事件不再有继承权限。为其他成员发送已安排的提醒前，重新核对群成员名单和创建者权限。撤销显式 Bot 授权后，QQ 设置仍可独立赋予本群权限。未经开放的群不会因管理员存在而自动启用。

## 风险分类

|指令/操作|风险|执行方式|
|---|---|---|
|help、role/list、名单查询、提醒list/show|只读|通过权限校验后直接执行|
|personal、privatepersona、grouppersona、groupmode、groupsettings|常规可逆设置|直接执行|
|whitelist add/remove、blacklist add/remove|可逆范围管理|通过作用域与目标保护检查后直接执行|
|role remove / role set QQ 1|撤销群权限|直接执行|
|role add / role set QQ 2|权限提升|保留90秒确认|
|globaladmin add/remove|高风险全局权限变更|仅主人，保留90秒确认|
|memory reset、群记忆 reset|清空当前有权范围的长期记忆|保留90秒确认；不静默清除其他会话|
|单条记忆及提醒修改/删除、循环提醒暂停/恢复|局部可逆管理|通过权限校验后直接执行|
|批量删除重要数据|高风险|本轮不新增此入口，不能通过自然语言绕过已有确认|

确认绑定发起者、私聊/群会话、具体操作与参数，90秒过期、单次消费，并在执行时复验权限。保留操作审计和撤权epoch。名单、权限变化会使相关在途群消息或旧提醒失效；失效提醒需要有权者明确修改时间或恢复后才重新绑定当前授权。

## 屏幕只读查看的接口要求（未实现）

现有自有模块中未发现已经授权、可独立调用的屏幕查看接口。P2F只记录设计，不新增截图入口，不调用任何屏幕或电脑操作工具。

未来接口应独立为 screen_read_only：主人和全局管理员可在私聊请求；群聊必须获取完整且最新的成员名单，并确认全员均为主人或全局管理员。成员信息不全、查询失败或出现任何其他成员均拒绝；实际发送截图前再查一次成员。不得仅依据当前发言者权限、群名或缓存的参与者判断。

该接口仅返回截图供分析，不携带键鼠、窗口、Shell、文件控制或Work授权。不得因开通截图查看而开通Work。Work尚未实现，本轮未运行电脑操作能力测试。
