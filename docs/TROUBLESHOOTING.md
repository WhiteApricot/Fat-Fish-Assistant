# 故障排查

| 现象 | 检查 |
| --- | --- |
| 安装报下载或校验失败 | 检查下载连接、许可和安装日志，重新运行安装向导复用已校验缓存。 |
| 已打开管理页但 QQ 无回复 | S1检查SnowLuma测试账号/Hook、OneBot、模型与群权限；连接ready仍无回复时查Core导入异常，避免从不含第三方组件的开发树启动。P2旧安装流程另查原通信实例。 |
| 重复启动或端口占用 | 查看管理页及启动日志。受管理实例会按身份复用；未知进程应由其所属应用处理。 |
| DIRTY 或索引校验失败 | 先保留诊断材料，按[运维指南](OPERATIONS.md)检查 Embedding 和数据一致性。 |
| 自然语言管理无反应 | 在正确会话检查 /naturalcommand，群内按触发条件 @，可用 /help 检查斜杠入口。 |
| 恢复包被拒绝 | 核对密码、包哈希、软件兼容及新空目录条件。 |

安装根 logs 和 instance/logs 用于本地诊断，分享前先清理账号、令牌、聊天及绝对路径。

若桌面入口报告活动发布与源码不同，从安装向导执行修复，待发布切换后重试。旧发布仍可通过既有回滚操作恢复。
