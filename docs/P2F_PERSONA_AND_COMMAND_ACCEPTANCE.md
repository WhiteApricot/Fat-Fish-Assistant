# 自然语言指令与人格系统升级验收

本轮基于 V10 工作包。验证使用独立 Local 实例、离线发布包和合成消息。真实模型探针只发送合成文本及测试编号。QQ 实机结果单独记录。

| 验收项 | 状态 | 核对内容 |
| --- | --- | --- |
| 自然语言开关 | 通过 | 私聊和群分别写入开关，群配置与私聊配置独立 |
| 关闭后的聊天及斜杠 | 通过 | 关闭时不调用命令分类，斜杠查询可用，斜杠可重新开启 |
| 提醒参数 | 通过 | 独立时间和事项字段，三种真实表达通过，事项包含「提醒」时原样入库，缺参不入库 |
| 私聊和群人格 | 通过 | list、set、add、edit、remove、reset、undo，编号稳定，错误编号无变更 |
| 全局权限与叠加 | 通过 | 主人和全局管理员可变更，群管理员被拒；未设置局部人格的会话取得全局要求，局部优先 |
| 重置与撤销 | 通过 | 局部和全局独立重置及恢复，旧设置兼容，已有权限确认路径保留 |
| 数值及对象 | 通过 | 冷却两分钟转换为 120 秒，中文条目序数、群号与 QQ 参数经真实模型抽样复测；已有日期、数量上限和作用域检查仍走原执行器 |
| 安全拦截 | 通过 | 缺参、无效编号、越权、模糊提及及跨作用域保护，编辑时复核原条目 |
| 一级、二级帮助和文档 | 通过 | 使用共享定义，核对命令清单与说明文档，内部路由与斜杠专用开关分别标注 |
| 原有功能回归 | 通过 | Local 14 组，100 个用例和 6 个脚本；交付包复跑状态、调度及原生群隔离 |
| 外部依赖 | 通过 | 复用原缓存与发布清单 |
| QQ 实机端到端 | 未测试 | 包括真群、真私聊中的开关、全局和局部人格呈现 |

完整指令见 [正式指令说明](P2F_COMMAND_REFERENCE.md)。真实模型抽样用于验证选定表达和参数。所有自然语言措辞的表现仍取决于现用模型。人格撤销按操作者和会话保存短期记录，进程重启后仅保留已写入的条目与开关。

正式目录复跑状态与权限套件通过。13 个交付文件逐一核对 SHA-256，程序文件同时与离线交付包一致。
