# Windows 换机

在源和目标 Windows 主机使用 **Migrate-Fat-Fish-Assistant.cmd**。提前准备可用的空安装目录和备份包存放位置。

1. 在源主机按所用平台的方式停止机器人。QQ 通过 SnowLuma 官方界面停止。在 FFA 迁移向导选择「迁出」，确认停止 FFA 并暂停源实例，保存 `.ffa.zip`，设置至少 12 字符的密码。
2. 迁出成功后，保留包和密码，并记录向导显示的 SHA256。源实例保持暂停。
3. 在目标主机选择「导入」，选择原包、输入密码和空安装目录，确认源实例仍已停止。向导校验包和数据，重建目标所需依赖，再激活目标实例。
4. 在目标完成收发验证。QQ 通过 SnowLuma 重新登录并接入 OneBot。飞书核对已迁入的应用与平台配置，再检查长连接及消息。
5. 如需撤回迁移，先停止并停用目标，再通过源主机向导确认恢复。一个机器人账号在同一时间只启用一个实例。

包中包括聊天、记忆、人格、身份、权限、用户插件配置和必要凭据。依赖文件会重新获取。SnowLuma 的官方配置、登录态和运行数据留在原平台。日常日志和临时诊断文件排除在迁移范围外。包内容经认证加密，密码丢失时无法导入。

密码错误、文件损坏、目标已有实例、依赖不兼容或数据一致性检查失败时，向导会拒绝导入。保留原包和源数据，再根据提示排查。[运维与恢复](OPERATIONS.md) · [数据与隐私](DATA_AND_PRIVACY.md)
