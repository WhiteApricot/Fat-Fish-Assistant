# 迁移操作与数据清单

> S2 批次 1 已将迁移计划限定为 FFA 自有数据。现有 Windows 冷迁移流程保留，完整迁移重构与跨平台验收属于后续批次。

普通用户只用 **Migrate-Fat-Fish-Assistant.cmd**；目录快照 backup/restore 保留给维护者，不要求用户执行命令或复制数据库。

## 迁出

1. 在源主机双击迁移脚本，选择“1 迁出”。先用官方方式停止 SnowLuma，然后确认迁出会停止 FFA 受管服务并让源实例保持暂停。
2. 使用保存对话框选择 .ffa.zip 位置，设置并确认至少 12 字符的密码。
3. 程序停止写入者，核验生命周期锁、PID、维护事务、SQLite 及原生向量一致性；不满足条件即拒绝。
4. 生成冷快照、逐文件 SHA256 清单及依赖/组件计划，打包并加密为一个 ZIP。屏幕显示大小、文件数和 SHA256。
5. 源实例写入迁出暂停记录，常规启动会拒绝重新消费这个 QQ。包生成失败也应保持停止，先查看诊断；不要盲目删除暂停记录。

## 迁入

1. 在目标 Windows 主机准备本项目，双击同一迁移脚本，选择“2 导入”。
2. 选择包、输入密码、选择新的空安装位置，确认源主机已停止并保持暂停，接受目标所需外部依赖许可。
3. 程序准备独立解释器/环境，验证认证标签、归档路径、文件清单、逐文件 SHA 和软件/数据库版本，自动获取固定版本依赖。
4. 用户数据先写入 staging；依赖资源重建、本机路径/端口调整、身份和 SQLite/FAISS 校验通过后才激活。目标已有实例或新聊天一律不覆盖。
5. 在目标通过 SnowLuma 官方渠道准备运行环境，重新扫码、配置并验证连接。迁移包排除 SnowLuma 配置、运行数据和登录态。

数据恢复成功与真实服务/QQ 验收分开报告。密码忘记不能恢复；密码不存文件或日志。源与目标不能同时消费同一个 QQ。确需撤销迁出时，先停止并停用目标，再在源主机安装向导的明确确认下撤销暂停；不要两边同时启动。

## 数据分类

|类别|具体位置/处理|
|---|---|
|实例和主人身份|instance.json 中的身份元数据（替换 release 路径）；private/instance-identity.json、p2c-access.json 等有效私密配置|
|权限/群边界|管理员、用户黑名单、群白名单/模式、群管理员映射、安全 salt/epoch、私聊设置原样保留，不新增授权|
|聊天与记忆|data 下所有持久化数据，包含 data_v4.db、plugin_data、LivingMemory SQLite/FAISS 和其他 SQLite 数据；SQLite backup 合并已提交 WAL 状态；插件原生历史备份原件保留，不混作活动索引或冒称已验证历史一致性|
|插件配置|data/config 全部；meme_manager/image_host/config.json 虽位于 data/plugins 内，也按用户配置保留，含其私密凭据|
|插件资源|data/plugins 中不属于固定程序的用户配置/资源，以及用户修改的非程序资源；程序代码按兼容版本重建|
|人格/资产|persona、data 内用户资源、实例自定义根目录，以及 models/engines/bin 中不属于已知固定运行依赖的用户资产|
|必要秘密|private 内有效 Key/令牌、插件配置中的必要秘密整体加密，不因目录私密而遗漏|
|重新获取|Python/虚拟环境、AstrBot/第三方插件程序、固定 FFmpeg、固定引擎/模型等依赖不重复装包，保存版本/组件计划后重建|
|不迁移|SnowLuma 的官方配置、运行数据、QQ 登录态和设备认证、日志、已知临时缓存、WAL/SHM 旁路文件、PID/运行标记/锁、安装归属证明、配置/索引修复/生命周期诊断历史|

缓存只按已知路径排除：data/temp、data/plugin_data/meme_manager/temp、字节码缓存等；不会因为自定义资源目录名恰为 temp 就全部排除。

## 加密与拒绝条件

使用 cryptography 的标准 AES-256-GCM，scrypt（N=32768,r=8,p=1）派生密钥，随机盐和 nonce；流式处理，兼容标准 AESGCM 解密。全部文件名和 manifest 位于密文中，外层 ZIP 只含 snapshot.aesgcm。认证完成后才解析/恢复内层 ZIP。安装计划 schema 2 仅登记 FFA 组件，拒绝上一代安装计划。临时明文位于限制访问的目录。外层 ZIP 不是通用 WinZip 密码 ZIP。支持上限为 64 GiB 和 100,000 个内层文件，超限明确拒绝，不生成可声称成功但无法导入的包。

拒绝路径穿越、ADS、Windows 保留文件名、重复/大小写冲突、符号链接、文件/目录冲突和超限解压。拒绝未知数据版本、软件/补丁不匹配、损坏 SQLite、未完成升级或无法确认的活动写入者。graph_memory、未知向量格式、链接数据、实例外资源引用、未受清单管理的插件代码需要专门适配；不能保证完整性时失败并指出配置/诊断位置，不宣称迁移成功。
