- 身份 — 主人私聊
- 步骤 — 发送「重置私聊人格」，再用不同说法询问上次做了什么。接着执行一条不同类型的安全指令，查询最新一次和先前的人格重置回执。

## R-02 引用近期操作继续处理

- 身份 — 主人私聊
- 步骤 — 给专用测试账号授予全局管理员并确认。用自己的说法撤销刚授予的权限，核对确认前后名单。另创建两项不同的测试提醒，按内容指代其中一项修改，再用模糊说法测试。
- 预期 — 全局管理员撤销仍需确认。明确指代只修改对应提醒。目标或改动含糊时先提示明确，不执行。转述他人指令或讨论操作方法不会触发管理。
