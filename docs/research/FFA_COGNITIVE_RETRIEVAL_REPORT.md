# FFA 认知检索实验与验收报告

本轮选择 E 作为继续验证的实验入口。冻结集的回答证据和澄清结果优于其他方案，但仍有错答，暂不接入 Gateway，也不据此宣布 N01 通过。研究基线是 `1023da5dcb6ee372b8dc0212441d3bb7cf95c3f1` 加八个已有的未提交新库模块。实验分支在独立副本开展，原工作树、真实实例、权限和生产记忆均未变动。

时间和证据判断是本集最清晰的收益。词法让综合结果多对一道题。RRF 的分数在两条材料的集合里没有净改善，不能据此判断它在多通道大库的价值。当前保留可复现的 RRF 对照，暂缓增加图数据库、交叉编码器、生成式查询改写和常驻重排服务。实际复现的是 Hindsight 的独立通道思想、Graphiti 的发生时间和记录时间分离，以及 OpenClaw 的快慢路径思路。范围过滤、可信来源与 SQLite 修订使用 FFA 自己的实现。详细源依据及未移植机制见[源码研究](FFA_COGNITIVE_RETRIEVAL_RESEARCH.md)。

## 原 35 题复核

原文件和顺序保留。用既有公开经历脚本和锁定 BGE 复跑 22–30。22–24 仍为 0/3，25–29 返回空，30 在无模型路径命中。25–29 的旧脚本在写库前跳过私有或排除材料，空结果只能作为旧基线观测。其余 26 道需要尚未执行的真实聊天或不同功能验收，标记 NOT_RUN。没有以改写旧题或补造可信源升级旧题状态。

- **22 降雨。** 正确向量候选排第一，余弦 0.518 被 0.60 阈值提前排除。新算法允许低余弦候选参加排序，同时要求独立对象、时间或其他匹配证据。
- **23 验证。** 回顾旧记录与实际试验共享词义，旧夹具把两者都标作普通读操作。新入口能区分可信事件的动作和状态，旧素材的来源没有足够状态信息，因此不能声称复测转绿。
- **24 过河。** 日间旧桥的向量分数比夜间渡轮高。新入口用发生时段和主体进行区分，专门测试用可信时间证明可选择夜间事件。旧素材若只写末班而没有发生时间，仍需保留不确定。

## 限制与准出

已知冻结错误包括 4 道难负例得到旁支证据，以及显式二选一规则无法识别某些比较和上下文指代。确认类问题需进一步区分对象、主张极性和事件状态。新版不能用这批冻结题调参后重报通过。样本的双人独立复核也待完成。见[样本审查](FFA_COGNITIVE_RETRIEVAL_DATA_REVIEW.md)。

P95 37.17 ms 是缓存查询向量条件下的检索计时，覆盖 SQLite 候选与排序，略去数据入库、模型推理、网络和聊天生成。单独测量生成文档和查询向量的 Windows 本地 BGE 调用，P50 为 78.44 ms，P95 为 104.55 ms。不能相加两个 P95 得到端到端 P95。没有实测低配设备上的整套 AstrBot、BGE 与后台并发，因此 2 CPU/4 GiB 常驻目标和真实聊天 4–6.5 秒均不判通过。现有聊天调度未改动。

加入撤回复核后，在相同 150 题上单独复跑 E。冻结集仍为 32/50，难负例误答仍为 4/10，R@5 从 96.7% 降至 93.3%。缓存条件下 P50/P95 为 30.53/84.86 ms，其中累计 SQLite P95 为 65.77 ms。一次并发复跑曾在初始化夹具时遇到 SQLite 中断。重跑将夹具写入与计时查询隔开，生产读路径的限时仍保持原值。逐题日志为 `cognitive-retrieval-v1-final.json`。

Windows 定向套件首轮为 71/73。旧的已绑定 QQ 到飞书画像用例首轮没有得到画像，旧并发读写用例也曾测得 160.6 ms，超过自身 120 ms 断言。两项单独复跑均通过。测试断言和现有 Gateway 调用链均未修改。新用例覆盖可信时段、主体、他人私聊和其他群隔离、已取消事件、撤回后索引以及等待 BGE 时撤回证据。

WSL 在两个 CPU 和 4 GiB 虚拟内存上限下，新检索回归 5/5，测试进程峰值 RSS 31.5 MiB。该限制下复跑了 E 的全部 150 题，冻结集为 32/50，P50/P95 为 5.75/13.18 ms，进程峰值 RSS 为 36.1 MiB。这个测量依然使用缓存向量和小型合成 SQLite。逐题日志为 `cognitive-retrieval-v1-wsl.json`。

运行器与版本化夹具位于 [fixtures](fixtures/)。在工作区以 `PYTHONPATH=src` 运行 `evaluate_cognitive_retrieval.py`，将 `--vectors`、`--output` 指向 Local。使用 `--variants A,B,C,D,E,no_bm25,no_time,no_structure,no_rrf,no_rerank` 留下逐题的候选、采纳证据和决策。首次生成缓存需要相同的本地模型服务。完整测量保存在 Local 的 `reports/ffa-n01/cognitive-retrieval-v1-experiments.json` 和 `cognitive-retrieval-v1-old-pinned.json`。
