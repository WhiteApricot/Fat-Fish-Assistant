## P3 最小适配约束

在自有管理层按平台分离进程、文件权限、运行库与服务适配，保留管理 JSON 契约。Linux 建立锁定解释器/依赖清单与校验下载、独立实例、systemd 或等价受控生命周期、仅本机服务及最小跨主机认证通信。具体发行版与 Dagu 版本到 P3 再核验，不在本轮安装。

以 2 核 4GB 为原型约束，实测常驻/峰值内存、CPU、磁盘和并发；必要时减少原型组件，不强行常驻所有模型。覆盖鉴权拒绝、断线、重复任务、服务/主机重启和恢复。原型不等同于生产云，不开放未经授权的公网入口。
