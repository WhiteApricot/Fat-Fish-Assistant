# 消息处理

1. NapCat 将 QQ 事件经本机 OneBot 反向连接交给 AstrBot。网关从事件读取真实发送者、会话和群号，执行去重、白名单及黑名单检查。
2. 明确的斜杠命令由指令入口解析。开启自然语言指令时，可对符合触发条件的文本调用意图识别，再按同样的权限与确认规则执行。无法确定参数时要求澄清，普通聊天进入回复流程。
3. 私聊使用本人上下文。群根据 @、群模式、引用和冷却决定是否进入模型回复。涉及转发时先恢复结构化内容并标记为外部材料。
4. Guard 合并人格要求并按权限处理记忆与搜索。模型结果经发送前检查后由 AstrBot 和 OneBot 发回 QQ。授权撤销会影响尚未完成的会话。
5. 提醒插件通过 AstrBot 的定时调度独立检查到期任务。

参见 [权限](PERMISSIONS.md) 与 [事件约定](protocols/MESSAGE_EVENT_CONTRACT.md)。
