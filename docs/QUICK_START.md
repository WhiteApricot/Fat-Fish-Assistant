# 快速开始：双击操作

适用 Windows 10/11 x64。先审阅项目和第三方许可，准备聊天模型凭证。[飞书接入](LARK.md)使用 AstrBot 原生 Lark 适配器。[Windows QQ 接入](SNOWLUMA_WINDOWS.md)使用独立的 SnowLuma 和机器人 QQ 账号。

## 首次安装

双击根目录 **Install-Fat-Fish-Assistant.cmd**，按提示操作：

1. 确认默认安装位置；需要更改时输入 C，使用文件夹选择器。目录必须是新的空目录或已受管理的安装目录，不能选正式源码目录。
2. 阅读并接受所选组件的外部许可。选择是否安装长期记忆检索（Embedding）。QQ 和飞书直接发送的语音使用 DeepSeek 随聊天凭据提供的转写服务。
3. 安装器创建待验证的身份库。主人账号在通信接入后通过私聊验证。
4. 等待固定解释器、独立环境、固定上游源码/补丁、插件和模型安装。进度与日志会持续显示，下载或初次构建可能较慢，请保留窗口。
5. 在隐藏输入提示中填写 **DeepSeek API Key**。输入不回显，不出现在命令行参数或普通管理日志。

## 接入平台并开始聊天

1. 飞书按[接入指南](LARK.md)配置应用订阅、AstrBot 适配器和 FFA Provider。使用 QQ 时先按安装向导登记机器人号码，再按[独立接入指南](SNOWLUMA_WINDOWS.md)完成账号登录和 OneBot 反向连接。
2. 新实例在任一已接入平台的机器人私聊发送 `/owner`，按回复完成一次性验证码确认。已有主人时，可以用绑定流程跨平台共用身份。群聊需要由主人申请准入并确认。[账号与权限](PERMISSIONS.md)
3. 在当前会话发送 `/help` 查看可用功能。自然语言管理和联网搜索各有全局与会话开关，可按需要启用。[聊天指令](COMMAND_REFERENCE.md)

普通短回复可分条发送，代码块和长篇说明保持完整。新安装默认载入 Dejavu Moe 的 24 张鲸鱼娘 GIF，可在表情包管理页增加或替换素材。

只有缺少 Microsoft 运行库时，才会获取固定哈希的官方运行库安装程序并可能请求必要的 Windows 系统确认。拒绝确认会安全停止，已有数据保留。脚本不操作 QQ 窗口，不代替扫码，不改变全局 PowerShell 策略或系统 Python。

AstrBot Dashboard 用户名为 `astrbot`。首次启动时，肥鱼助手会用当前 Windows 用户的凭据保护 Dashboard 密码。修改 Dashboard 密码后，如果自动登录失效，设置入口会要求隐藏输入当前密码一次；通过原生登录验证后更新加密凭据，后续启动无需重复输入。启用二次验证时仍需在 Dashboard 完成验证，换 Windows 用户或主机后需重新更新凭据。新安装可按所选平台指南完成私聊和群聊验证。

可用 `/memory status` 查看长期记忆状态。私聊记忆按统一身份管理，群记忆默认关闭，获授权的群管理员可以在当前群启用。[长期记忆与命令](MEMORY.md)

## 日常启动

只需双击 **Start-Fat-Fish-Assistant.cmd**。安装位置从当前用户的本地登记读取；已有服务直接复用，未安装的可选组件跳过。可选服务失败会单独报告，核心 Chat 会继续尝试启动；涉及脏记忆数据时，若恢复所需 Embedding 不可用，则保留保护并拒绝 Chat 启动。

需要重新扫码时，从 SnowLuma 启动窗口进入官方 WebUI。关闭 FFA 窗口或用 Ctrl+C 停止 FFA 后，按 SnowLuma 官方方式单独停止通信服务。不要同时在两台主机启动同一个机器人身份。失败窗口会保留；按屏幕显示到安装根 logs 和 instance/logs 查看诊断，不要直接上传私人日志。

## 重复安装与修复

再次双击安装脚本时，可选择重复检查，或选择修复/继续中断安装。修复会先正常停止受管理服务，复用已校验的软件、保留聊天/记忆/身份/权限和已有 Key。同一依赖版本下的自有代码修复使用既有事务升级与回滚；上游版本、补丁或依赖清单改变时拒绝当作普通修复。

安装中断后重新运行向导，选择同一受管理目录。未知目录和无归属证明的实例不接管。错误密码、损坏包、数据库损坏或不支持状态都不能通过删除标记解决。

## 迁移到新主机

**Migrate-Fat-Fish-Assistant.cmd** 处理 FFA 自有数据。SnowLuma 由用户在源端通过官方方式停止，并在目标端通过官方流程重新接入。操作范围和源实例暂停要求见 [迁移指南](MIGRATION.md)。
