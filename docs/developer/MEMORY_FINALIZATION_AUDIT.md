## 真实模型隔离探针

本轮第一轮成功复跑记录了两段文本及结束帧，创建 3 条活动。调度器耗时 1,703 ms，真实生成耗时 531 ms，使用 49 / 22 输入与输出 Token。新库抽取、规划、证据选择分别 1,469、469、906 ms，用量为 511 / 99、292 / 20、295 / 11。单一合成状态用例得到 1 条 Claim 和 1 条支持证据，执行撤回后剩 0 条。三条合成设备重复检查形成 1 条 Observation，撤回两条后剩 0 条。调度器使用专用本地阶段，2 秒级结果不能用于确认正式聊天目标。

随后在新增 Schema 及结束帧判断的工作树上复跑，调度器 1,937 ms，真实回复 516 ms，49 / 20 Token。抽取、规划和证据判断为 1,016、844、391 ms，Token 为 511 / 97、292 / 20、293 / 11。Claim、Observation 的合成形成与撤回断言再次通过。

最新工作树上的隔离探针再次记录两段文本和结束帧。调度器 1,985 ms，真实生成 625 ms，49 / 20 Token。新库抽取、规划与选择分别为 781、844、734 ms，对应 511 / 97、321 / 20、291 / 11 Token。一次 Claim 与一次 Observation 均在撤回后退出召回。
