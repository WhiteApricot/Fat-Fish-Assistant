# 当前记忆系统

`GatewayMemory` 从已经准入的事件生成 `Access`，再调用 `MemoryService`。授权私聊以 Principal 为范围，群聊以完整 Conversation Key 为范围。统一记忆启用后，私聊默认开启，群记忆默认关闭。群卡片共享须由群管理员开启，跨作用域使用仍要核对来源。会话历史由 AstrBot 单独管理。

| 数据 | 当前作用 |
| --- | --- |
| Scope 与 Access | 限定读写范围、目的、受众及当前授权。Access 由受信宿主建立并在使用时复核。 |
| Source 与 Activity | 记录平台、实例、Bot、账号、会话以及带事件 ID、时间、类型、状态和证据的活动。Agent 操作记录用 operation ID 关联计划、审批、运行和最终结果。 |
| Fact 与版本 | 按作用域与键保存事实、重要度、修订及证据。修订和删除使用版本检查。 |
| Memory Card | 以活动证据形成叙事卡片，支持合并、编辑、归档和检索。卡片记录可追溯到来源，并受原范围授权约束。 |

## 写入、召回和清理

入站承认后，记忆桥按配置记录入站活动，正文捕获和事实提取可以分别控制。确认发送的回复和主动投递可记录出站活动。受信调用方可用 `record(access, activity)` 写活动，用 `put_fact(...)` 写事实。缺失、过期或跨范围授权会拒绝操作。外部候选活动须有来源和回执，计划不能当成已发生事件。

`search(access, query)` 返回范围内候选事实。`card_records(access, ...)` 读取卡片。`context(access, query, ...)` 生成受预算限制的上下文。召回使用词法检索、记忆清晰度与衰减，配置嵌入服务后可加入向量匹配。后台维护负责部分整理、归档与索引补齐。向量不可用时仍可走词法路径。

删除、重置及核验后的撤回会处理相关事实、活动、卡片投影或索引，并记录擦除信息。授权变化会在后续读写时复核，失去来源权限的共享内容不再用于召回。恢复旧快照需保留已有擦除。把新数据接入记忆前，应明确可撤回边界以及派生索引如何清理。

## 候选记忆库与恢复

独立的 Cognitive Memory 存储使用 `ffa-cognitive-memory.sqlite3`。打开库时验证安装身份和独立擦除水位，重放删除账本。候选库启用 SQLite WAL。词法倒排在提交快照里仅读取候选 ID，正文仍须经过当前读权限和有效来源复查。已撤回项即使仍出现在较早的倒排快照，也不能通过后续正文查询。

恢复候选库时通过 `--memory-controls` 提供留在快照和恢复目标之外的独立控制目录。缺少可信水位或账本密钥的恢复会失败。普通聊天仍由 MemoryService 处理。

## 显式经历检索实验

`EventRetrieval` 是独立的实验入口，当前 Gateway 尚未调用。调用方传入由可信准入生成的 `Audience`、问句和检索时刻。SQLite 先限定可见范围，再读取有当前修订和有效支持来源的事件。词法与 BGE 候选按顺位融合。事件发生时间、主体、状态和对象影响排序或阻止回答。等待向量期间若撤回来源，候选发布前的复查会剔除失效事件。结果区分 `answer`、`clarify`、`abstain`，并给出条目修订、事件和证据 ID。

模型超时时可继续使用词法与事件候选。存储或证据复查不可用时返回拒答。该入口仍有错误确认和指代歧义问题。见[认知检索报告](../research/FFA_COGNITIVE_RETRIEVAL_REPORT.md)。

当前 E 路径先完成词法和向量召回，再从 SQLite 读取可见的事件证据。事件查询优先检查各通道前八个条目，其余空间按发生时间填充，总计最多 48 条证据行。来源在向量计算后才读取，因此向量等待期间的撤回不会被旧候选覆盖。

确认类问题要求可信证据同时支持动作、状态和问题中的对象片段。只有共同词片段、相近向量或相同时段仍不足以确认。解析器将「昨晚」「昨天」「今天」与事件发生时刻的本地日期比较。询问具体指代时，有两个以上可见、可信且与约束相容的不同事件才会请求澄清。检索暂不解析用户第一人称经历，识别到这类主体时拒答。对象核对使用原文片段，包含改写、别名和混合事件的材料仍可能被漏判或误判。

多事件问法只组合通过主题、主体、状态、日期和证据检查的事件，按事件 ID 去重。宽泛查询触及返回上限时要求缩小范围。日期支持上一个自然周，时段按配置时区解释。公开街道核查的通用问法有独立入口，仅查询公开范围，且跳过模型调用和含具体地址编号的材料。普通个人住址、账号和密钥仍适用原保护。

识别到明确日期时，在 SQLite 证据读取阶段应用日期窗口，再计算候选上限。历史问句的证据组合在有界的候选池内完成，诊断界面仍只显示领先候选。能识别动作且没有其他主题限定的开放式历史问句，可以组合相同动作的事件。含有明确主题的问句仍要求主题证据。过多的匹配会触发澄清。
