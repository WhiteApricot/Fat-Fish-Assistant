日期：2026-11-01。交付状态：本地候选版本完成，等待用户审核及人工登录验收。未进入 P2F，未同步正式工程、未提交或推送 GitHub。

## 结果与统计口径

本轮已调整依赖结构和分发策略，并非只清理旧缓存。新的默认核心环境是 **141 个包**，原完整环境为 160 个；其余 **19 个包按需补装**。已完成最终清单的干净安装、原生启动/停止、本机模拟对话、本地模型推理、权限群聊回归和加密迁出迁入。

指定 NewA 样本只用于只读体积审计，没有使用其账号、密钥、聊天或数据库进行测试。源码改动和主要合成实例保存在 `Fat-Fish-Assistant.local/deep-optimization`，源码候选位于其 `source` 子目录；另复用并补充了 `Fat-Fish-Assistant.local/cache` 中的公开固定缓存及来源记录。遵循 WORKFLOW.md 的源码与实例分离原则，本轮按用户要求把编辑留在 local，待审核后再同步唯一正式源码工程。

同功能组合包括 QQ、长期记忆、语音及原有三个插件。样本已经包含上一轮 167.20 MiB 缓存去重，因此下表使用去重后的样本作为本轮基线，不重复计算上一轮收益。

最终核心环境在原生运行、增量补装及回滚后核对为 141 个发行包，没有缺包或额外自动安装的包。运行分发中的 851 个 AstrBot 核心及必要根文件与上一轮已验收发布逐一核对，均存在且哈希相同。NapCat 的负向篡改测试仅在独立副本注入故障，拒绝启动验证后已还原到固定原包字节；交付和最终运行样本没有该测试改动。

聊天 NumPy 2.5.4、语音 NumPy 2.2.6 的锁不同。本轮保留语音隔离环境，没有为省空间擅改上游所需版本。三个已验收插件仍默认安装，不调整其核心代码和启用语义。旧的完整环境不会自动删包；无法确定用途的包继续保留。

安装和运行资源使用硬链接后，禁止就地改写固定模型、引擎或 FFmpeg；需要替换时通过固定版本安装和原子换文件操作。修改任一硬链接路径都会影响同一文件的其他路径，后续完整性校验会拒绝变化。迁移不会把此实现当作普通用户数据链接放行，而是验证固定资源后在目标重建。

## 按需启用、兼容与回滚

普通用户需要其他平台或文档工具时，可双击 `Enable-Full-Dependencies.cmd`。它复用原有许可提示，先正常停止服务，再补齐完整依赖，完成后由用户重新启动。初次安装也可明确选 `install --dependency-profile chat`；新的默认为 core。语音、Embedding 等继续通过原安装向导的修复/功能选择启用。

增量安装先检查固定核心版本、可选包版本冲突，再获取并验证所有可选 wheel。只添加原清单中缺失的包，不覆盖核心版本；成功通过完整组版本校验和 pip check 后才原子提交环境标记。普通异常会撤销本次新增包；中断记录保留原始新增清单，避免重试后失去回滚依据。来源不明或版本冲突的现有可选包不会覆盖。

回到 core 的维护方式：停止并禁用已配置的其他平台/文档工具后，用本实例解释器运行 `scripts/Rollback-Optional-Dependencies.py --root <安装目录> --confirm-optional-features-disabled`。仅删除已记录为本次新增的可选包，验证核心与 pip check 后恢复原标记；不会自动启动服务。正常增量安装和回滚已实测，中断重试状态有自动回归覆盖。

修改前源码、依赖清单和配置模板保存在 `deep-optimization/baseline-source.zip`。正式工程仍是上一轮状态，可直接继续原版本。代码级回滚可恢复该归档中的对应文件；不要覆盖运行数据。若回退到上一轮始终使用完整组的代码，应先补齐完整组，再切换入口。原 chat/speech/assets/source 锁和数据格式保持兼容，迁移计划新增核心配置及其哈希校验；旧迁移包默认按完整组恢复，避免静默丢失原有可选功能。

硬链接回滚为独立副本时，先复制到旁边临时文件，验证 SHA256 后原子替换原路径；缓存可按同一版本重新下载。以上均无需修改第三方核心，也不降低权限或系统安全设置。

**设置页自动登录。** 安装和日常启动均可打开已交接本机登录状态的 AstrBot 设置页，`-NoBrowser` 保持不打开网页。新增 `dashboard_login.py` 通过本机保存的账号、密码调用原生登录 API，再取得自有 `fat_fish_health` 的原生受限插件页面。该同源页面从 URL 片段接收会话信息，先清除片段、再验证会话，按 AstrBot 自身使用的浏览器存储键保存登录状态后跳转。密码不写入 URL，完整会话 Token 不放在查询参数、管理日志或临时文件里；账户首次安全升级标记按原生逻辑保留并跳转安全设置。缺凭据、账户改动或二次验证时保留手动登录，不绕过鉴权。交接窗口 60 秒；这不是服务端一次性 Token，也不改变原生会话有效期。
