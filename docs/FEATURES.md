# 肥鱼助手用户功能总览

Fat-Fish-Assistant 使用 AstrBot 接收聊天事件。支持的 Provider 共用命令、身份、权限和记忆服务。功能按当前会话授权启用。

| 功能 | 可以怎么用 |
|---|---|
| 私聊和群聊管理 | 普通成员可私聊。获准群的成员可按群模式发起对话，被封禁的账号除外。群管理员可设为仅 @ 或智能参与。智能参与会判断是不是在问机器人，并限制插话频率。`/groupmode` 查看当前模式，`/groupsettings` 查看群冷却设置。|
| 连续消息与回复节奏 | 可以分几条说完一个问题。上一轮还未发出且能安全合并时，肥鱼会合并消息，从最近一条重新计时。飞书纯文本按发送人和会话收集，通常等待 4 秒的消息间隔。QQ 私聊沿用现有合并与分条节奏。|
| 联网查公开资料 | 全局和当前会话联网搜索均已开启时，可以直接问天气、近期消息或专业问题，也可以说「上网核对一下刚才的说法」。肥鱼根据问题和已有资料决定是否搜索，对照网页证据复核，必要时再查。最终答复沿用当前会话的口吻和分条节奏。你要求出处或结论需要核实时才附来源。用 `/webresearch` 查看状态、`/webresearch off` 关闭当前会话联网、`/webresearch on` 恢复。|
| 人格与回答偏好 | `/persona list` 查看当前私聊或群的人格条目，`/persona add 先说结论` 追加要求。授权管理者可用 `/globalpersona` 维护全局要求。个人可以用 `/personal 简短`、`/personal 标准`、`/personal 详细` 选择回复长度。`/new` 开启新的私聊对话。|
| 长期记忆 | `/memory remember 键 内容` 保存本人资料，`/memory search 关键词` 检索，支持修改、删除和确认重置。获授权的群管理员可以管理当前群记忆。私聊记忆和群记忆各自隔离，检索需要已配置的嵌入服务。|
| 提醒 | 自然语言指令开启时可以说「明天下午提醒我拿快递」，也可直接用 `/remind add 十五秒之后叫我去喝水`。模型提取时间和事项，程序精确到秒校验并安排提醒。到期后通过原会话发送人格化提醒。支持查看、调整时间和内容、暂停、恢复及删除。获授权的群管理者可为指定群成员设置群提醒。|
| 引用和合并转发 | 引用当前会话的消息，或发送合并转发后问「请概括里面的结论」。肥鱼优先识别明确引用，补充已取得的上游引用和邻近消息。飞书可读取的历史取决于应用权限。嵌套记录取不到时会说明缺失，素材中的话不会变成管理命令。|
| 图片、语音、文本附件 | 可以发图并补充问题。已启用语音识别时可以用语音提问。发送小型纯文本附件后可以要求读取和总结，支持 txt、md、csv、json、log、yaml、yml，单轮最多 3 份、合计 64 KiB。|
| 表情包 | 可说「给我发个开心的表情包」，再说「再来一个」或「没看到，重新发一下」。在当前会话短时间内会延续这次请求。普通聊天仍可按配置搭配表情包。|
| 权限和名单 | `/role` 查看自己的权限。主人、全局管理员和群管理员按各自范围管理。`/whitelist` 管理获准使用的群，`/blacklist` 管理相应范围的访问限制。|
| 自然语言操作与确认 | 全局和当前会话的自然语言指令均开启时，可以用日常语言操作人格、提醒、记忆和权限。执行后先发送系统回执，再发送人格化补充。无法确定是否是管理请求时会继续聊天。需确认的操作用 `/confirm` 或 `/cancel`，`/history` 查看近期回执，`/undo` 撤销符合条件的操作。`/naturalcommand off` 可关闭当前会话的自然语言管理，斜杠指令仍可用。|
| 安装与运维 | Windows 安装向导 管理 AstrBot、Core 和可选本地模型，独立显示 SnowLuma 登记、反向连接及账号证据。SnowLuma 由用户在官方界面操作。跨机数据迁移见[迁移指南](MIGRATION.md)，目标服务与 QQ 需分别验收。|

语音发送、发送合并转发、主动文件工作、QQ 电话、电脑控制、以及 Work/DSH 不属于本指南的使用范围。

命令参数和场景示例见 [指令手册](COMMAND_REFERENCE.md)。权限与数据使用说明见 [权限](PERMISSIONS.md) 和 [数据与隐私](DATA_AND_PRIVACY.md)。
