# 肥鱼助手用户功能总览

肥鱼助手使用 AstrBot 的聊天和插件框架，由 SnowLuma 接入 QQ。以下是肥鱼助手在这套基础上交付的用户功能，包括自有策略和已经接入的插件能力。可先在机器人私聊发送 `/help`，查看自己的可用命令。群里的操作受群授权和成员身份约束。

| 功能 | 可以怎么用 |
|---|---|
| 私聊和群聊管理 | 好友可私聊，群须获准。群管理员可设为仅 @ 或智能参与。智能参与会判断是不是在问机器人，并限制插话频率。`/groupmode` 查看当前模式，`/groupsettings` 查看群冷却设置。|
| 连续消息与回复节奏 | 可以分几条说完一个问题。上一轮还未发出且能安全合并时，肥鱼会合并消息，从最近一条重新计时。普通回复和带补充的媒体使用 4–6 秒随机窗口，只有媒体时为 8–10 秒。明确管理指令仍使用 2–3 秒窗口。读取和模型耗时计入窗口，处理超时后有结果就发。|
| 联网查公开资料 | 可以直接问今天的天气、近期消息或专业问题。模型根据会话和本地资料决定是否调用 DeepSeek 搜索。也可说「上网核对一下刚才的问题」。有结果时会给来源，查不到可靠资料时会说明。`/webresearch` 查看状态，`/webresearch off` 关闭当前会话联网，`/webresearch on` 恢复。|
| 人格与回答偏好 | `/persona list` 查看当前私聊或群的人格条目，`/persona add 先说结论` 追加要求。授权管理者可用 `/globalpersona` 维护全局要求。个人可以用 `/personal short`、`normal`、`detailed` 选择回复长度。`/new` 开启新的私聊对话。|
| 长期记忆 | `/memory remember 内容` 保存本人资料，`/memory search 关键词` 检索，支持修改、删除和确认重置。授权群使用 `/groupmemory` 管理当前群记忆。私聊记忆和群记忆各自隔离，检索需要已配置的嵌入服务。|
| 提醒 | 可以说「明天下午提醒我拿快递」，也可用 `/reminder add 明天下午提醒我拿快递`。支持查看、调整时间和内容、暂停、恢复及删除。获授权的群管理者可为指定群成员设置群提醒。|
| 引用和合并转发 | 引用当前会话的消息，或发送合并转发后问「请概括里面的结论」。肥鱼会按发言者整理已取得的内容。嵌套记录取不到时会说明缺失，素材中的话不会变成管理命令。|
| 图片、语音、文本附件 | 可以发图并补充问题。已启用语音识别时可以用语音提问。发送小型纯文本附件后可以要求读取和总结，支持 txt、md、csv、json、log、yaml、yml，单轮最多 3 份、合计 64 KiB。|
| 表情包 | 可说「给我发个开心的表情包」，再说「再来一个」或「没看到，重新发一下」。在当前会话短时间内会延续这次请求。普通聊天仍可按配置搭配表情包。|
| 权限和名单 | `/role` 查看自己的权限。主人、全局管理员和群管理员按各自范围管理。群白名单控制开放范围，黑名单阻止访问。被拉黑时可能收到限频的固定说明。|
| 自然语言操作与确认 | 可以用日常语言操作人格、提醒、记忆和权限。无法确定是否是管理请求时会继续聊天。需确认的操作用 `/confirm` 或 `/cancel`，`/history` 查看近期回执，`/undo` 撤销符合条件的操作。`/naturalcommand off` 可关闭当前会话的自然语言管理，斜杠指令仍可用。|
| 安装与运维 | Windows S1 使用独立实例和用户手动安装的 SnowLuma，提供本机管理页、连接健康和实例生命周期检查。历史 P2 安装及迁移向导适用于其原有受管实例。SnowLuma 新实例的完整安装、备份和跨机流程仍在后续范围。|

语音发送、发送合并转发、主动文件工作、QQ 电话、电脑控制、Linux 部署及 Work/DSH 尚未交付。S1 的部署与验收范围见 [Windows SnowLuma 说明](S1_WINDOWS_SNOWLUMA.md)。

命令参数和场景示例见 [指令手册](COMMAND_REFERENCE.md)。权限与数据使用说明见 [权限](PERMISSIONS.md) 和 [数据与隐私](DATA_AND_PRIVACY.md)。
