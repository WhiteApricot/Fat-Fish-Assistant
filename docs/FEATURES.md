# 功能与限制

- QQ 私聊与授权群可进行模型聊天。群支持仅 @ 和智能参与模式，智能模式使用决策组件和冷却规则。
- 人格要求按基础、全局和会话层合并，会话要求优先。用 /persona 管理当前范围，用 /globalpersona 管理全局。
- /memory 和 /groupmemory 分别处理本人记忆和当前群记忆。长期记忆检索取决于 LivingMemory 和配置的嵌入服务。
- /reminder 支持增删改查、暂停和恢复。提醒调度随运行中的 AstrBot 调度器工作，默认时区 Asia/Taipei。
- 合并转发可作为聊天材料读取。引用内容不会继承发送人的管理权限。
- 安装可选语音识别后才能转写相应音频。自定义提醒音频、QQ 电话和电脑控制暂未开放。

参数与使用示例见 [指令手册](COMMAND_REFERENCE.md)。
