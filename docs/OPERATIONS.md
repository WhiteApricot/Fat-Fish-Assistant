# 运维与恢复

Windows 用户从源码根目录的 CMD 入口管理肥鱼助手。向导会识别已登记的安装目录。[快速开始](QUICK_START.md)

| 场景 | 操作 |
| --- | --- |
| 日常运行 | 双击 **Start-Fat-Fish-Assistant.cmd**。已运行的受管服务会复用，未安装的可选组件会跳过。关闭窗口或按 Ctrl+C 停止 FFA。 |
| 更新或修复 | 从更新后的源码运行 **Install-Fat-Fish-Assistant.cmd**，选择修复并使用原受管理安装目录。可复用已校验的依赖，保留身份、聊天、记忆、设置与模型凭据。依赖或上游改变时，按向导所示的兼容要求处理。 |
| 异常退出 | 使用安装向导修复。若提示数据库或向量索引状态不明，保留原数据与日志，按提示检查后重试。涉及向量恢复时需要对应的嵌入服务。 |
| 端口占用 | 在失败窗口查看冲突端口，确认是哪一个应用正在使用。修复时可为可选本地模型重新选择可用端口。 |
| QQ 掉线 | 在 SnowLuma 官方 WebUI 查看登录状态，并按提示完成扫码或设备验证。通道联通后，仍需在 QQ 客户端验证实际收发。[QQ 接入](SNOWLUMA_WINDOWS.md) |
| 飞书无回复 | 在开放平台核对已发布的事件订阅和凭证，再检查私聊或群准入。[飞书接入](LARK.md) |
| 换机 | 使用 **Migrate-Fat-Fish-Assistant.cmd**。确认目标完成验证前，源实例保持暂停。[迁移](MIGRATION.md) |

更新失败时先查看向导提示。回滚使用受管理发布入口，保留原聊天与记忆数据。日志保存在安装目录，分享前清除账号、令牌、消息与本机路径。[故障排查](TROUBLESHOOTING.md) · [数据与隐私](DATA_AND_PRIVACY.md)
