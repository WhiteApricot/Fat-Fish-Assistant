# Fat-Fish-Assistant（肥鱼助手）

肥鱼助手通过 AstrBot 提供私聊和群聊，可按会话设置人格、查询长期记忆、创建提醒、处理引用和媒体，并通过权限控制管理操作。

当前安装指南适用于 Windows 10/11 x64，通过 SnowLuma 和 OneBot 接入 QQ。SnowLuma 需独立安装，QQ 登录由用户在官方界面完成。飞书接入与跨平台实机联调仍待验证。
