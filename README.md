# Fat-Fish-Assistant（肥鱼助手）

肥鱼助手通过 AstrBot 提供私聊和群聊，可按会话设置人格、使用长期记忆和提醒、处理引用和媒体，以及在授权范围内调用管理和联网搜索工具。

支持 Windows 10/11 x64。飞书使用 AstrBot 内置 Lark 适配器长连接。Windows QQ 提供独立 SnowLuma 与 OneBot 的接入指南。
